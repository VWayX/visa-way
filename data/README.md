# Data

`passport-index-matrix-iso2.csv` is the [Passport Index dataset](https://github.com/ilyankou/passport-index-dataset) by Ilya Ilyankou (MIT license), data up to January 2025.
First column = passport (from), other columns = destination (to). Values: number of visa-free days, `visa free`, `visa on arrival`, `eta`, `e-visa`, `visa required`, `no admission`, `-1` (same country).
Source of the underlying information: https://www.passportindex.org
